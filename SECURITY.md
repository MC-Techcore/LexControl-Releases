# Seguridad y privacidad

## Estado de RC3

Versión candidata de prueba. La compilación superó siete pruebas automatizadas y la auditoría de dependencias Python no reportó vulnerabilidades conocidas en esa ejecución. Esto no certifica el ejecutable ni sus componentes nativos.

Trend Micro generó una alerta pendiente de clasificación. No ejecutar si el antivirus bloquea el programa; no deshabilitar protecciones ni crear exclusiones para realizar pruebas.

## Datos locales

Utilizar únicamente documentos ficticios. El cifrado y la protección por contraseña no están implementados en RC3. Conservar la carpeta Datos y evitar compartirla. Los informes exportados y las copias abiertas en aplicaciones externas pueden contener información documental.

## Reportar un problema

Contactar de forma privada al responsable que proporcionó la versión. Indicar versión, sistema operativo, pasos para reproducir y mensaje de error. No publicar contratos, credenciales, registros sensibles ni muestras de documentos privados en GitHub.
